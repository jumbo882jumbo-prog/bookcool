# 📋 ข้อกำหนดความต้องการของระบบ (System Specification & Requirements)

> **ชื่อโครงการ:** ระบบร้านขาย E-Book และระบบบริหารจัดการหลังบ้าน (Bookcool E-Book Store System)  
> **หมวดหมู่งาน:** E-Commerce Web Application / Database Management System  
> **สถานะโครงการ:** พัฒนาและเชื่อมต่อระบบสมบูรณ์ (Active Production Ready)  

---

## 1. ภาพรวมของระบบ (System Overview)

**Bookcool** คือเว็บแอปพลิเคชันร้านค้าหนังสือดิจิทัล (E-Book Store) ครบวงจร ที่รองรับกระบวนการตั้งแต่การเลือกชม ค้นหา สั่งซื้อ ชำระเงินจำลอง (Mock Bank Transfer / PromptPay) การตรวจสอบหลักฐานการโอนเงินโดยผู้ดูแลระบบ (Admin Slip Verification) ไปจนถึงการปลดล็อกสิทธิ์ดาวน์โหลดไฟล์ E-Book ให้แก่สมาชิก

ระบบถูกออกแบบด้วยสถาปัตยกรรม **Client-side & Hybrid Cloud Database** ที่ผสานการทำงานระหว่าง:
1. **Frontend Interface:** Responsive Web Application พัฒนาด้วย Semantic HTML5, CSS3 (Tailwind CSS) และ Vanilla JavaScript ES6+
2. **Backend & Cloud Database:** เชื่อมต่อฐานข้อมูล **Supabase (PostgreSQL 15)** พร้อมระบบ Real-time WebSockets และ fallback ด้วย LocalStorage / AlaSQL In-Memory Database
3. **API Service:** Flask Python REST API สำหรับจัดการข้อมูลหนังสือและการทำ Automated Testing

## 2. กลุ่มผู้ใช้งานและสิทธิ์ในระบบ (User Roles & Permissions - RBAC)

ระบบใช้การควบคุมการเข้าถึงตามบทบาท (Role-Based Access Control: RBAC) แบ่งผู้ใช้ออกเป็น 3 ระดับ:

| บทบาทผู้ใช้ (Role) | สิทธิ์การเข้าถึงและการทำงานหลัก | หน้าจอที่เกี่ยวข้อง |
| :--- | :--- | :--- |
| **ผู้เยี่ยมชมทั่วไป (Guest)** | • ค้นหาและดูแคตตาล็อกหนังสือทั้งหมด<br>• ดูรายละเอียดหนังสือ เรื่องย่อ และรีวิว<br>• เพิ่มหนังสือลงตะกร้าสินค้าชั่วคราว | `index.html`<br>`book-detail.html`<br>`cart.html` |
| **สมาชิก / ลูกค้า (Customer / User)** | • สิทธิ์ของ Guest ทั้งหมด<br>• สั่งซื้อสินค้าและยืนยันบิลคำสั่งซื้อ<br>• อัปโหลดภาพสลิปจำลองหลักฐานการโอนเงิน<br>• เข้าถึงหน้า "คลังหนังสือของฉัน" (My Library)<br>• **ดาวน์โหลดไฟล์ E-Book เฉพาะเล่มที่ได้รับอนุมัติแล้ว (`approved`)** | `checkout.html`<br>`my-books.html`<br>`login.html` |
| **ผู้ดูแลระบบ (Admin)** | • สิทธิ์ของ User ทั้งหมด<br>• ตรวจสอบรายการสั่งซื้อและรูปภาพสลิปการโอนเงิน<br>• อนุมัติ (`Approve`) หรือปฏิเสธคำสั่งซื้อ<br>• เพิ่ม/แก้ไข/จัดการรายการ E-Book ในร้านค้า<br>• ดูแดชบอร์ดสรุปยอดขายและการวิเคราะห์ 4 มิติ (Analytics Dashboard)<br>• รันคำสั่ง SQL Query บนคอนโซลฐานข้อมูล (SQL Console) | `admin.html`<br>`reports.html`<br>`sql-console.html`<br>`add-book.html` |

## 3. ข้อกำหนดเชิงฟังก์ชัน (Functional Requirements: FR)

### FR-01: การสืบค้นและคัดกรองหนังสือ (Catalog & Real-time Search)
* **FR-01.1:** ระบบต้องแสดงรายการหนังสือทั้งหมดพร้อมรูปภาพหน้าปก, ชื่อเรื่อง, ผู้แต่ง, ราคา, และหมวดหมู่
* **FR-01.2:** ระบบต้องรองรับการค้นหาแบบข้อความแบบเรียลไทม์ (Instant Search) ทั้งจากชื่อหนังสือและชื่อผู้แต่ง
* **FR-01.3:** ระบบต้องรองรับการกรองตามหมวดหมู่ (ธุรกิจ & การตลาด, วรรณกรรม, AI, การเงิน, เทคโนโลยี)
* **FR-01.4:** ระบบต้องรองรับการจัดเรียง (Sorting) ตาม: มาใหม่ล่าสุด, ราคาต่ำไปสูง, ราคาสูงไปต่ำ

### FR-02: การจัดการตะกร้าสินค้า (Shopping Cart Management)
* **FR-02.1:** ผู้ใช้สามารถกดปุ่ม "ใส่ตะกร้า" ได้จากหน้าแรกและหน้ารายละเอียดหนังสือ
* **FR-02.2:** ระบบต้องแสดงจำนวนสินค้าบนไอคอนตะกร้าสินค้า (Cart Badge) แบบเรียลไทม์
* **FR-02.3:** ผู้ใช้สามารถปรับเพิ่ม/ลดจำนวน หรือลบรายการสินค้าในหน้า `cart.html` ได้
* **FR-02.4:** ระบบต้องคำนวณยอดเงินรวมสุทธิ (Grand Total) อัตโนมัติ

### FR-03: การสั่งซื้อและชำระเงินแบบจำลอง (Checkout & Mock Payment)
* **FR-03.1:** ระบบต้องแสดงรายการสินค้า ยอดชำระ และ QR Code พร้อมเพย์จำลองสำหรับโอนเงิน
* **FR-03.2:** ผู้ใช้ต้องกรอกชื่อ-นามสกุล, อีเมล และอัปโหลดไฟล์รูปภาพสลิปหลักฐานการโอนเงิน
* **FR-03.3:** เมื่อกดยืนยัน ระบบจะสร้างรหัสคำสั่งซื้อใหม่ (รูปแบบ `ORD-YYYY-XXX`) บันทึกสถานะเริ่มต้นเป็น `pending` (รอตรวจสอบ)
* **FR-03.4:** ระบบจะทำการล้างตะกร้าสินค้า (`cart_items`) อัตโนมัติหลังสร้างคำสั่งซื้อสำเร็จ

### FR-04: การปกป้องเนื้อหาและการดาวน์โหลด E-Book (Digital Rights & Content Protection)
* **FR-04.1:** ผู้ใช้สามารถตรวจสอบประวัติการซื้อของตนเองได้ที่หน้า `my-books.html`
* **FR-04.2:** **เงื่อนไขความปลอดภัย:** หากคำสั่งซื้อมีสถานะเป็น `pending` ระบบต้องขึ้นป้ายสถานะ "⏳ รอแอดมินอนุมัติ" และ**ล็อกปุ่มดาวน์โหลด**
* **FR-04.3:** เมื่อแอดมินอนุมัติคำสั่งซื้อเป็น `approved` แล้ว ระบบจะปลดล็อกและแสดงปุ่ม "📥 ดาวน์โหลด E-Book" ทันที

### FR-05: การตรวจสอบและอนุมัติบิลคำสั่งซื้อ (Admin Order Verification)
* **FR-05.1:** แอดมินสามารถเปิดดูรายการคำสั่งซื้อทั้งหมด ตรวจสอบยอดเงิน และคลิกดูภาพสลิปขยายเต็มตา
* **FR-05.2:** แอดมินสามารถกดปุ่ม "✅ ยืนยันคำสั่งซื้อ" (Approve) เพื่อเปลี่ยนสถานะคำสั่งซื้อ
* **FR-05.3:** เมื่อคำสั่งซื้อได้รับการอนุมัติ ระบบจะกระจาย Event ให้หน้าลูกค้าปลดล็อกปุ่มดาวน์โหลดทันที

### FR-06: ระบบรายงานและวิเคราะห์ข้อมูลยอดขาย (Sales Analytics & Reporting)
* **FR-06.1:** แดชบอร์ดในหน้า `reports.html` ต้องสรุปตัวชี้วัด 4 มิติ: ยอดขายรวม (Total Revenue), จำนวนคำสั่งซื้อ (Orders), จำนวนหนังสือที่ขายได้ (Books Sold), และสัดส่วนคำสั่งซื้อที่อนุมัติแล้ว
* **FR-06.2:** แสดงกราฟแนวโน้มยอดขายตามช่วงเวลา (Revenue Trend Chart)
* **FR-06.3:** แสดงกราฟโดนัทสัดส่วนยอดขายแยกตามหมวดหมู่ (Sales by Category Donut Chart)

### FR-07: คอนโซลรันคำสั่ง SQL (SQL Query Console Studio)
* **FR-07.1:** หน้า `sql-console.html` รองรับการพิมพ์คำสั่ง SQL (SELECT, JOIN, GROUP BY, WHERE)
* **FR-07.2:** มีปุ่ม Preset Queries (เช่น 5 อันดับหนังสือขายดี, ยอดขายรายวัน, รายการรอตรวจสอบ)
* **FR-07.3:** ประมวลผลและแสดงผลลัพธ์เป็นตารางข้อมูลพร้อมปุ่ม Export ข้อมูล

## 4. ข้อกำหนดเชิงคุณภาพ / ไม่ใช่ฟังก์ชัน (Non-Functional Requirements: NFR)

| รหัส | หัวข้อ | ข้อกำหนดเชิงคุณภาพ |
| :--- | :--- | :--- |
| **NFR-01** | **Performance (ประสิทธิภาพ)** | • หน้าแรกและหน้ารายละเอียดหนังสือต้องโหลดเสร็จภายใน 1.5 วินาที<br>• การค้นหาและกรองหนังสือทำงานแบบ Real-time โดยไม่กระตุก (Instant Filter < 100ms) |
| **NFR-02** | **Security (ความปลอดภัย)** | • ปกป้องลิงก์ดาวน์โหลด E-Book ไม่ให้บุคคลภายนอกเข้าถึงได้ก่อนอนุมัติสิทธิ์<br>• ป้องกัน XSS Injection โดยทำการ Sanitize ข้อความก่อนแสดงผลใน DOM<br>• มีระบบจำกัดสิทธิ์หน้าแอดมิน (Admin Route Guard) ป้องกันผู้ใช้ทั่วไปเข้าถึง |
| **NFR-03** | **Accessibility (การเข้าถึง)** | • ออกแบบตามมาตรฐาน **WCAG 2.1 Level AA**<br>• รองรับ Keyboard Navigation (Tab, Enter, Escape)<br>• อัตราส่วนคอนทราสต์ของสีข้อความไม่ต่ำกว่า 4.5:1<br>• รูปภาพทุกรูปมีข้อความกำกับ (alt text) ครบถ้วน |
| **NFR-04** | **Usability & Responsiveness** | • รองรับการแสดงผลบนอุปกรณ์ทุกขนาด (Mobile, Tablet, Desktop)<br>• UI สวยงาม ทันสมัย ชัดเจนตามหลัก Visual Hierarchy |
| **NFR-05** | **Reliability & Data Sync** | • รองรับการซิงค์ข้อมูลสองทาง (Dual-storage Sync) ระหว่าง Supabase Cloud Database และ LocalStorage Fallback ทำให้ระบบไม่สะดุดแม้เครือข่ายมีปัญหา |
| **NFR-06** | **Maintainability & CI** | • มีชุดการทดสอบอัตโนมัติ (Automated Unit Tests) ครอบคลุมเส้นทางหน้าเว็บและ API<br>• มีไปป์ไลน์ Continuous Integration (GitHub Actions CI) ตรวจสอบความถูกต้องทุกครั้งที่ Push Code |

## 5. แผนผังเส้นทางและ API Endpoints (Route & API Specification)

| เส้นทาง (Route / URL) | วิธีการ (Method) | บทบาทที่อนุญาต | หน้าที่การทำงาน |
| :--- | :---: | :---: | :--- |
| `/` หรือ `/index.html` | GET | ทุกคน | แสดงแคตตาล็อกหนังสือ ค้นหา และกรองหมวดหมู่ |
| `/book-detail.html?id=:id` | GET | ทุกคน | แสดงรายละเอียดเรื่องย่อ ราคา และรีวิวของหนังสือ |
| `/cart.html` | GET | ทุกคน | ดูและจัดการรายการหนังสือในตะกร้าสินค้า |
| `/checkout.html` | GET / POST | สมาชิก | กรอกข้อมูลการสั่งซื้อและอัปโหลดหลักฐานการโอนเงิน |
| `/my-books.html` | GET | สมาชิก | คลังหนังสือส่วนตัวและดาวน์โหลดไฟล์ E-Book |
| `/login.html` | GET / POST | ทุกคน | เข้าสู่ระบบ สมัครสมาชิก และสลับบทบาทจำลอง |
| `/admin.html` | GET / POST | แอดมิน | ตรวจสอบสลิปและกดยืนยันอนุมัติคำสั่งซื้อ |
| `/reports.html` | GET | แอดมิน | แดชบอร์ดสรุปสถิติและกราฟแสดงยอดขาย |
| `/sql-console.html` | GET / POST | แอดมิน | สตูดิโอเขียนและรันคำสั่ง SQL Query |
| `/api/books` | GET | ทุกคน | ดึงข้อมูลรายการหนังสือทั้งหมดในรูปแบบ JSON |
| `/api/books` | POST | แอดมิน | เพิ่มรายการหนังสือเล่มใหม่เข้าระบบ |
